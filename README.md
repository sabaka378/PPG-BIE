# PPG Mod

**Модификация для People Playground через BepInEx.**  
Добавляет в игру новые механики, исправляет баги и расширяет возможности контекстного меню для ванильных предметов.

> **Канал в Telegram:** [t.me/bie_ppg](https://t.me/bie_ppg) — там выходят все обновления, релизы и новости мода.  
> **Релизы и changelog:** смотрите раздел [Releases](https://github.com/sabaka378/PPG-BIE/releases) на GitHub.

---

## Важно перед установкой

Мод **не работает**, если путь к игре содержит **кириллицу** или другие **не-ASCII символы**.  
Пример рабочего пути: `C:\games\People Playground\` или `D:\SteamLibrary\steamapps\common\People Playground`

---

## Установка как сборка

1. Скачайте архив с игрой из последнего релиза
2. Скопируйте папку People Playground из архива в любую удобную папку без кириллицы в пути (примеры выше)
3. Запустите People Playground.exe
Необязательно: можно добавить ярлык игры на рабочий стол (ПКМ по файлу People Playground.exe → Отправить → Рабочий стол (создать ярлык))

## Установка как мод

1. Скачайте из [Releases](https://github.com/sabaka378/PPG-BIE/releases) файл PPGMod.dll
2. Скачайте BepInEx и поместите папку BepInEx в корневую папку игры
3. Скопируйте файл PPGMod.dll в папку \People Playground\BepInEx\plugins
4. Запустите People Playground.exe
